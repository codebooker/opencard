# OpenCard roadmap

OpenCard is a free, single-business self-hosted product. This is a list of useful next improvements, not a paid-tier plan.

- Make first-run setup clearer: a guided brand → location → card checklist and validation of optional integrations.
- Improve admin navigation and mobile editing, especially long card forms and the relationship between templates, locations, and cards.
- Add tested one-command disaster recovery for the complete database-and-uploads backup, with scheduled backup status visible to an owner.
- Add automated dependency scanning and a repeatable container smoke test to CI.
- Expand API reference and provide copyable examples for SCIM, directory import, and webhooks.
- Add accessible, lightweight analytics charts while retaining downloadable reports.

See [README.md](../README.md) for supported features and [deploy/README.md](../deploy/README.md) for deployment.
